The Cipher Challenge

This is the introductory page of my website that will show how I used Python to help do some of the tasks associated with the National Cipher Challenge 2026. Python is a popular and accessible coding language that is very useful for manipulating 'strings'.

Strings

'Strings' are the class of data that consists of individual characters that are 'strung together' in a specific order. For example, "Hello" is a string of five characters - "H", "e", "l", "l" and "o"

Being able to manipulate strings is useful when it comes to cryptography as both the ciphertext and plaintext versions of a message can be stored as strings. Furthermore, we can code programs that convert a plaintext to a ciphertext (encryption), and a ciphertext to a plaintext (decryption).
